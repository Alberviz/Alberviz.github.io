# Alberto Vizcaíno Ponte - Portfolio & Krakount Showcase

Live at **[https://alberviz.github.io](https://alberviz.github.io)** · Krakount Showcase at **[https://alberviz.github.io/krakount](https://alberviz.github.io/krakount)**

Personal engineering portfolio and flagship product showcase built with **Next.js (Static Export)**, **React 19**, **TypeScript**, **Tailwind CSS v4**, **Motion**, **GSAP**, and **Phosphor Icons**.

## Development

```bash
pnpm install
pnpm dev          # http://localhost:3000
pnpm typecheck    # TypeScript strict verification
pnpm build        # Static export to ./out
```

## Design Engineering Handoff

- `PRODUCT.md`: Audience, positioning, and strict content/privacy rules (`impeccable` schema v1).
- `DESIGN.md`: Surface tokens (`Obsidian + Emerald` on `/`, `Kazimierz at Night` on `/krakount`), typography, layout rules, and motion engineering curves.
- `CLAUDE.md` & `docs/CLAUDE_DESIGN_PROMPT.md`: Ready-to-run design & animation brief for Claude Code.
