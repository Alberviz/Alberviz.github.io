# Alberto Vizcaíno Ponte - Portfolio

Live at **[https://alberviz.github.io](https://alberviz.github.io)**. `/wari` is a short link to [Wari](https://wariapp.es).

Static portfolio built with **Next.js (static export)**, **React 19**, **TypeScript**, **Tailwind CSS v4**, **Motion**, WebGL and **Phosphor Icons**.

## Development

```bash
pnpm install
pnpm dev          # http://localhost:3000
pnpm typecheck    # strict TypeScript
pnpm build        # static export to ./out
```

## Docs

- `CLAUDE.md`: structure, content files and hard rules.
- `PRODUCT.md`: audience, tone, content and privacy rules.
- `DESIGN.md`: tokens, typography, motion and composition.
